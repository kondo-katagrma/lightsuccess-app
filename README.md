# マネジメントスケジュール診断（チーム共有版）

診断ツールをアプリ化し、**法人ごとの診断結果をチームの共有台帳に蓄積・閲覧・比較**できるようにしたものです。

- **アプリ本体**：`index.html`（GitHub Pages で全員に配布）
- **共有データ**：Google スプレッドシート（全員が閲覧・集計できる台帳）
- **中継**：`apps-script/Code.gs`（アプリ ⇄ スプレッドシート をつなぐ小さなプログラム）

```
[メンバーのブラウザ] ──診断・保存──▶ [Apps Script] ──追記──▶ [共有スプレッドシート]
        ▲                                                        │
        └──────────────── 一覧・比較（読み込み）──────────────────┘
```

---

## セットアップ（初回だけ・近藤さんが実施）

### 手順1：共有スプレッドシートを作る
1. Google ドライブで新しいスプレッドシートを作成（名前は「診断台帳」など任意）。
2. チームメンバーに**閲覧（または編集）権限**で共有しておく。
3. **法人名リスト（開始時に選ぶ一覧）**について。
   - アプリは **`records` シート以外の「最初のシート」のA列** を法人名の一覧として読み込みます。
   - 既存の取引先マスタ（A列＝取引先名）をそのまま使えます。見出し行（`取引先名`／`法人名`）や空セルは自動で除外されます。
   - 別のシート・別の列を使いたい場合は `Code.gs` の `MASTER_SHEET`（シート名）と `MASTER_COL`（列番号）を設定。
   - ※ 一覧に無い法人は、開始画面で**そのまま手入力**もできます。

### 手順2：Apps Script を貼り付ける
1. そのスプレッドシートで **拡張機能 → Apps Script** を開く。
2. 既定の `コード.gs` の中身を全部消し、`apps-script/Code.gs` の内容を丸ごと貼り付ける。
3. `TOKEN` は `index.html` と一致する値が設定済みなので**そのまま**でよい（変えるなら両ファイル同じ値に）。
4. 保存する（フロッピーアイコン）。

> **Code.gs を更新したら必ず再デプロイ**：Apps Script は貼り付け・保存だけでは公開版に反映されません。
> 右上 **デプロイ → デプロイを管理 → （鉛筆で編集）→ バージョン＝新バージョン → デプロイ** を行うこと。URLは変わりません。

### 手順3：ウェブアプリとしてデプロイ
1. 右上 **デプロイ → 新しいデプロイ**。
2. 歯車（種類の選択）→ **ウェブアプリ** を選ぶ。
3. 設定：
   - 説明：任意
   - **次のユーザーとして実行**：自分（近藤さん）
   - **アクセスできるユーザー**：**KatagrMa（katagrma.co.jp）内の全員**
     （＝社内限定。この選択肢は Apps Script が組織アカウントのスプレッドシート上にあるときに表示されます。「自分のみ」だとメンバーが使えないので選ばないこと）
4. **デプロイ** を押し、表示される **ウェブアプリのURL**（`https://script.google.com/macros/s/……/exec`）をコピー。
   - 初回は Google の承認画面が出るので許可する。

### 手順4：アプリにURLとトークンを設定
`index.html` の先頭付近、`CONFIG` を編集：

```js
const CONFIG={
  API_URL:"https://script.google.com/macros/s/……/exec",  // ← 手順3のURL
  TOKEN:"kata-2026-xxxx"                                    // ← 手順2で決めた TOKEN と同じ
};
```

### 手順5：GitHub Pages で公開
1. このフォルダを GitHub リポジトリにする：
   ```bash
   cd lightsuccess-app
   git init
   git add .
   git commit -m "診断アプリ（チーム共有版）初版"
   git branch -M main
   git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git
   git push -u origin main
   ```
2. GitHub のリポジトリ **Settings → Pages** で、Source を **main / (root)** にして保存。
3. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される。
   このURLをメンバーに配れば、全員が同じアプリを使い、結果が共有台帳に貯まります。

## 使い方（メンバー）

1. 配布URLを開く。
2. 最初に **法人を選択**（登録済みマスタから選ぶ／手入力）して診断を開始。
3. **「診断する」** で設問に回答 → 年間プラン／半年のライトサクセスが表示される。
4. 打合せ中は、結果画面の **打合せメモ欄** にその場で記入 → **「この結果を保存」**。
   - 一度保存するとボタンが **「メモを更新して保存」** に変わり、同じ画面で追記しても**同じ行を上書き**します（重複行はできません）。
5. **「蓄積一覧・比較」** タブで、全法人の保存結果・メモ・観点の傾向・開始月の分布を確認。
   - 各行の **「プラン・メモを表示」** でプランとメモを再表示。**メモはここで後から追記・修正でき**、「メモを保存（この行を上書き）」でその行を更新できます。
6. プラン内の **テンプレ名（▸付き）** をクリックすると、面談テンプレの設問や自己評価テンプレの一覧が表示されます。

## よくある調整

- **TOKEN を変えたい**：`Code.gs` と `index.html` の両方を同じ値にして、Apps Script を**再デプロイ**（デプロイ → デプロイを管理 → 編集 → 新バージョン）。
- **項目を増やしたい**（事業所コード・地域など）：`Code.gs` の `getSheet()` のヘッダーと `handleSave` の `appendRow`、`index.html` の保存フォームに列を足す。
- **スプレッドシートで直接集計したい**：台帳シートはそのままピボット・フィルタで使えます（payload列は再表示用のデータなので触らないこと）。
- **テンプレの中身を直したい**：プラン内のテンプレ名（▸付き）をクリックすると内容が表示されます。面談テンプレの設問は `index.html` の `TEMPLATES` に埋め込み済みです。元の面談テンプレ／自己評価テンプレのスプレッドシートを更新したら、`TEMPLATES` も合わせて手直ししてください（自己評価はリンク表示なので基本そのままでOK）。

## 注意（社内限定運用）
- アクセス範囲を **KatagrMa（katagrma.co.jp）内の全員** にしているため、**メンバーは自分の組織Googleアカウントでブラウザにログインしている状態**でアプリを使う必要があります。ログインしていないと保存・一覧の読み込みが失敗します（別のGoogleアカウントでログイン中の場合も同様。組織アカウントに切り替えて使ってください）。
- このアプリの通信はscriptタグ（JSONP）方式で、ログイン中のGoogleセッションのCookieが自動で送られるため、組織限定デプロイでもそのまま動きます。追加のログイン画面がアプリ内に出ることはありません。
- 台帳には法人名・担当者名が入ります。個人が特定される回答自由記述などは保存していません（診断は選択式のみ）。
- 動かないとき（社内限定特有）：①メンバーが組織アカウントで未ログイン → ログインで解決。②`Code.gs` を直した後に**再デプロイ（新バージョン）**していない → 反映されない。③スプレッドシートが個人アカウント側にある → 「組織内の全員」の選択肢が出ない。組織ドライブ上で作り直す。
